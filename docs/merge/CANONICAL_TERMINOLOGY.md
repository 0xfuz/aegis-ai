# Canonical Terminology

This vocabulary governs all post-Phase-0 Aegis-AI design. It does not alter
current routes, UI labels, database tables, or runtime behavior.

| Canonical term | Definition | Trust class | Current Aegis equivalent | CIOS donor equivalent |
|---|---|---|---|---|
| **Investigation** | The Aegis core work container that owns facts, inferences, and verdicts related to one security matter. UI may call it a **Case**. | Container | `Investigation` | `Case` |
| **Case** | User-facing synonym for an Investigation, never a second persisted business object. | Container | Investigation workspace | Case |
| **Alert** | An externally supplied detection/signal that may create, update, or attach to an Investigation; it is not evidence or a case. | FACT | Connector webhook payload plus created Investigation | No separate model |
| **EvidenceItem** | Immutable original bytes plus acquisition metadata and hash. | FACT | No equivalent; `Evidence` is an IOC chip only | `EvidenceItem` |
| **EvidenceParseRun** | Immutable record of one parser/version attempting to derive records from an EvidenceItem. | FACT | No equivalent | `EvidenceParseRun` |
| **RawRecord** | Immutable line/object/segment emitted by a parse run, retaining exact source representation/reference. | FACT | `RawEvent` only partially overlaps; `EvidenceRecord` is derived summary | `RawRecord` |
| **Event** | Deterministically normalized observation derived from RawRecord. It is the canonical timeline source. | FACT | `TimelineEvent`, `EvidenceRecord` | `Event` |
| **Indicator** | Canonical organization-scoped identity for a normalized observable such as an IP, domain, URL, hash, or email. | FACT identity; analyst verdict separately | `IOC` | `Indicator` |
| **IndicatorOccurrence** | Provenanced observation that a RawRecord/Event contains an Indicator. | FACT | IOC sighting counter only | `IndicatorOccurrence` |
| **Entity** | Canonical identity for an actor/object in an Investigation: host, user, IP, domain, file, process, etc. | FACT identity | Asset and graph nodes partially overlap | `Entity` |
| **EntityObservation** | Provenanced observation of an Entity in a RawRecord/Event. | FACT | No equivalent | `EntityObservation` |
| **EntityRelationship** | A deterministic, evidence-backed edge between two Entities. It is the factual investigation graph. | FACT | Derived graph edge only | `EntityRelationship` |
| **Finding** | Analyst-confirmed security conclusion, scoped to an Investigation and supported by facts and/or reviewed inferences. | VERDICT | No dedicated model; root cause is mutable AI text | `Finding` |
| **AttackTechnique** | Versioned ATT&CK catalog record, not an assertion that an attack occurred. | Reference FACT | MITRE strings | `AttackTechnique` |
| **AIAnalysis** | Immutable, versioned output of one Aegis model run against a factual input snapshot. | INFERENCE | Mutable Investigation AI fields | No equivalent |
| **Hypothesis** | A proposed explanation generated by an AIAnalysis; it is not a Finding. | INFERENCE | `alternative_hypotheses` JSON | No equivalent |
| **Recommendation** | A proposed action generated by an AIAnalysis; analyst decisions are separate verdict records. | INFERENCE | `RecommendedAction` | No equivalent |
| **ReasoningStep** | Ordered, structured explanation of an AI inference linked to supporting/contradicting facts. | INFERENCE | `reasoning_chain` JSON | No equivalent |
| **ReportSnapshot** | Immutable report content generated from a declared Investigation state/data cutoff. | VERDICT artifact | On-demand report bytes only | `ReportSnapshot` |
| **AuditEvent** | Append-only record of actor/system action, target, time, and metadata. | VERDICT governance | No case audit table | `AuditLog` |

## Normative terminology rules

1. “Evidence” means immutable source material, never an IOC chip, timeline
   summary, AI claim, or analyst note.
2. “Event” means deterministic normalization. AI may interpret an Event but
   cannot create, alter, or reclassify it as a fact.
3. “Indicator” is an observable identity; an occurrence is the provenance of
   seeing it. A malicious/suspicious label is a verdict, not the Indicator.
4. “Entity relationship” means an evidence-derived observation. Claimed causal,
   attack-stage, or attribution links are AI inferences unless analyst-confirmed.
5. “Finding” is reserved for an analyst-confirmed conclusion. AI root cause,
   MITRE mapping, confidence, or recommendation is always a proposal first.
6. Existing Aegis API field names remain compatibility names until a separately
   approved API retirement phase.
