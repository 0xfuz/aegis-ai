# Workspace Trust Semantics

- **FACT** — canonical evidence-derived records and relationships.
- **AI INFERENCE** — AIIE output; strict validation and analyst review still apply.
- **ANALYST VERDICT** — a Finding or confirmed MITRE mapping produced through explicit analyst action.

The UI labels these boundaries so an AI proposal is never presented as confirmed. Provenance navigation follows Findings or MITRE mappings to their AIIE source and supporting canonical facts, then evidence.
