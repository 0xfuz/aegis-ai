# Demo Investigation Pack

The Demo Investigation Pack is repository-owned synthetic training data. It never downloads external datasets and does not represent real people, organizations, systems, or incidents.

Load a scenario from **Investigations → Try Demo Investigation**. Each scenario is ingested through the existing canonical evidence parser and includes a completed, approved demo notebook, MITRE mappings, findings fields, graph-ready facts, and a report generated by the existing report endpoint.

| Scenario | Synthetic evidence | Learning objective |
| --- | --- | --- |
| Brute Force Attack | SSH authentication failures and successful login | Trace failed attempts, attacker IP, user, and authenticated access. |
| Phishing Campaign | Email header, URL, domain, attachment and browser events | Follow sender/recipient and phishing infrastructure indicators. |
| Ransomware Incident | Windows-style process, PowerShell, registry, C2 and file activity | Recognize execution, persistence, C2, and impact. |
| Insider Threat | Login, USB, privilege and file-copy activity | Evaluate unusual user behavior and data movement. |
| Web Application Breach | Nginx-style access events, SQL injection and webshell activity | Connect exploited endpoint, attacker IP, webshell, and command activity. |

Loaded demos are per-organization and cannot be imported twice. The Demo Loader can delete only its own demo investigation, including its synthetic evidence and derived canonical records; it does not affect manually created investigations.
